# Brand

GraftQL is named after *grafting*: joining a new branch (the scion) onto an established rootstock so they grow as one plant. Your SQL models are the rootstock; GraftQL grafts a typed GraphQL graph onto them.

## Name

- Write the product name as **GraftQL** in prose.
- The package and import name is `graftql` (`pip install graftql`, `import graftql`).
- Public classes use the `Graft` prefix: `GraftModel`, `GraftRouter`, `GraftLoader`.
- The wordmark is set in lowercase: **graft** in ink, **ql** in green.

## Logo

The mark is a dark stem (the SQL rootstock) wrapped in lime grafting tape, with a green GraphQL graph growing from the union.

## Colors

| Name | Hex | Use |
|---|---|---|
| Ink | `#0B2E22` | Rootstock, wordmark text, header |
| Graft green | `#1F9D66` | Graph on light backgrounds, links |
| Bright green | `#3DD68C` | Graph on dark backgrounds |
| Bud lime | `#B5E33F` | Graft tape and top node, highlights only |
| Mist | `#E6F4EC` | Text and stem on dark backgrounds |

## Don'ts

- Don't recolor the mark outside this palette or add effects such as shadows or gradients.
- Don't stretch the mark or set the wordmark in another font.
- Don't write the name as "Graft QL", "GraphQL Graft" or "graftQL".
